# Keyboard reader & fake input generator (Linux)
The project contains two simple C programs and a Makefile:
* keyboard_reader - reads and prints raw data from an input device (for example \/dev\/input\/eventX),
* fake_input - generates example input events in struct input_event format and writes them to \/tmp\/fake_event,
* Makefile - automates building and running both programs.
  
# Requirements
* Linux system
* C compiler (for example gcc)
* Kernel headers with linux\/input.h (usually provided by a linux-headers package)
  Files
* main.c - implementation of the keyboard_reader program
* fake_input.c - implementation of the fake_input program
* Makefile - build and run rules
  
# Building
  In the project directory run:
```bash
  make
```
The make (or make all) command builds two executables:
* keyboard_reader
* fake_input (to simulate input events)

# Running
```bash
  sudo ./keyboard_reader
```
* With an explicit device path:
```bash
  sudo ./keyboard_reader /dev/input/event3
```
* With a test file (for example generated by fake_input):
```bash
  sudo ./keyboard_reader /tmp/fake_event
```
  Stop the program with Ctrl+C.

# Automations

Please refer to the Makefile for additional automation rules, such as running fake_input and keyboard_reader in sequence.
